# Issam Matoussi · Course Library

Website for my students (academic year 2026–2027).

## How to update the site
1. **Add a PDF:** open the `pdfs` folder → *Add file* → *Upload files* → *Commit changes*.
2. **Show it on the site:** open `data.js` → click the pencil ✏️ → copy one material block,
   change `id`, `title`, `course`, `cat`, `date` and `file` (e.g. `pdfs/my-file.pdf`) → *Commit changes*.
3. Wait about one minute, then refresh the site.

Rubrics (`cat`): `courses`, `notes` (lecture notes), `booklets`, `books`.
